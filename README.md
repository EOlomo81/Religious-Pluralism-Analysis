# Religious-Pluralism-Analysis

# Religious Pluralism and Social Change: The Role of Religion in Nigerian Society

This project explores how religion shapes social change in Nigeria using qualitative data from open-ended survey responses. The analysis was conducted using Python for keyword extraction and Excel for thematic coding and visualization.

## Project Structure

- `data/`: The cleaned dataset used for thematic grouping.
- `report/`: Full written analysis with interpretations, findings, and theoretical contributions.
- `code/`: Python code used for extracting key terms from raw data.

## Methodology

- **Thematic Analysis**: Responses were grouped based on recurring keywords into themes such as:
  - Religious Diversity & Coexistence
  - Religious Conflict & Division
  - Religion and Education
  - Religion and Governance
  - Public Attitudes Toward Religion

- **Tools Used**: 
  - Python (NLTK + Scikit-learn for keyword extraction)
  - Microsoft Excel for organizing, coding, and analyzing data

## Key Findings

- Nigerians frequently interact across religious lines but still draw boundaries around marriage and governance.
- Younger respondents are more open ideologically but still report high exposure to religious tension.
- Governance is seen as both necessary and biased in managing religious diversity.

## Disclaimer
This project blends AI-assisted insights with human judgment. Quotes were paraphrased to preserve anonymity.
